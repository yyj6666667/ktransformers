KT CPU 前向精度排查简报
2026-10-20

已定位数值差异来源，并在已测范围内实现 CPU 前向误差归零。
当前主要问题是 prefill（处理输入阶段）的性能代价仍较大。

测试结果

模型为 Qwen3.5-35B-A3B，LoRA 关闭，黄金基准采用固定的 Transformers 实现。
两边使用相同的 8 个样本、每样本 32 个固定前缀位置；黄金实现保持不变。
下表为整模最后一层 hidden state 的平均绝对误差（abs mean）：

累计修改状态                                  末层误差
原始 KT                                       0.0131596
移除 down 分片舍入 [R1]                       0.0131247
对齐舍入 [R2–R5] 和专家相加顺序               0.0128956
CPU 数值规则全部对齐                          0，全部 40 层均为 0

中间阶段为诊断性消融，最终结果已在实际 KT CPU 算子的兼容模式中验证。
路由专家计算仍在 CPU 上完成。对齐舍入与相加顺序后，固定输入的单层误差下降约 99.55%，
整模末层误差仅下降约 2%；继续对齐内积累加规则和激活函数数值后，才实现归零。

改了什么

差异来自 BF16 舍入位置、专家相加顺序，以及 CPU/GPU 数值计算规则不同。
舍入位置调整如下：

标记    位置                      调整
R1      down 分片输出             移除分片 FP32 → BF16 舍入
R2      完整专家输出              在加权前增加 BF16 舍入
R3      SiLU 激活输出             在乘 up 前增加 BF16 舍入
R4      专家输出乘路由权重        在累加前增加 BF16 舍入
R5      专家结果累加              从最后舍入一次改为每次相加后舍入

此外，按黄金的专家 ID 顺序相加，并在 CPU 上匹配 decode、prefill 的内积数值规则。

性能与下一步

相同配置的单层 MoE 算子测试中，decode（逐 token 生成）耗时基本持平；
prefill 在 128、512 tokens 下，耗时分别为原来的 4.32 倍、9.10 倍。
精度对齐已在当前测试范围内完成，prefill 性能优化仍是后续重点。

下一步：补齐最后几项修改的独立消融，降低 prefill 开销，再验证 backward 和 RL 训练效果。
本轮结论限于固定 RTX 5090 软件配置下的前向测试，尚不代表 RL 训练效果已验证。

技术细节与证据：同目录“舍入位置技术说明.txt”、逐层误差表及性能记录。
